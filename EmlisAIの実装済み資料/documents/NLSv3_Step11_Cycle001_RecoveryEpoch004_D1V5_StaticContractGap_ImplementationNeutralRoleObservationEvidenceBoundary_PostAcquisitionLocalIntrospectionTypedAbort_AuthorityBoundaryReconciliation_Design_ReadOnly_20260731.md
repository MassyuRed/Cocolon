# 5. Post-acquisition local-introspection typed abort

## 5.1 Why a separate terminal is required

An exact17 observation requires a completely formed `after` exact14 and
post-acquisition module exact3.  If either cannot be formed after the live
attempt, there is no valid observation identity.

The following are forbidden:

- copying `before` into `after`;
- inserting null or a sentinel into exact14;
- using the last successfully read partial value as a complete identity;
- claiming source or executor drift when the value was not observed;
- constructing closure/projection against a nonexistent observation; or
- erasing the already-consumed live attempt.

The terminal must therefore be a distinct body-free abort record.

# Emlis チュートリアル再設計

2026-11-26 JST

同じ架空の記録を、自分で残し、Emlisの言葉を受け取り、ピースにして、分析で振り返る。ホームを使い始める前に、この一往復を自分の操作で体験できるようにする。

## 画面と操作

| 画面 | 表示と操作 |
|---|---|
| はじめに | 「Emlis(エムリス)」の下に「サンプルの記録で、Emlisを試してみましょう。」と表示する。操作は「はじめる」「あとで」。 |
| ホームで記録 | サンプルの出来事と気持ちを二欄に表示する。感情「平穏」・強さ「中」・カテゴリ「仕事」を選択済みで表示し、「この内容でOK」を押す。 |
| Emlisから | 記録に沿った問いを一つ表示する。見本の回答を選ぶと、その回答を踏まえた返答が現れる。次に「ピースの作成」へ進む。 |
| ピースを作る | サンプルの内容を整えた文章を画像プレビューに表示する。色を切り替えて「非公開で保存する」を押す。「自分のピースを開く」で保存したときと同じ画像を見られる。 |
| 投稿と感情通知の見本 | ピース画面の「投稿」に、相互フォローの相手として用意した架空のユーザー「かれん」の投稿を表示する。「練習で投稿する」を押すと自分の練習投稿も並ぶ。自分の投稿と、フォロー中の相手が自分に公開した投稿を読めることを案内する。「感情通知」を開くと、「かれん」が残した感情・強さ・時刻を表示する。受信をオンにすると、フォロー中の相手が公開した感情入力が通知で届くことを伝える。 |
| 分析 | 「こころグラフ」の週の見本を表示し、棒または日付を押すと選んだ日の内訳が出る。「わたしマップを見る」で別の日のサンプルと照合した一文を読み、「関係する部分を図で見る」で二項目の小図を開く。「まとめを見る」で進む。 |
| 使い方のおさらい | 下の一覧をその場で表示する。主操作「自分の記録をはじめる」で通常のホームへ戻る。 |

画面内の一覧は用語を覚えさせるための説明文を重ねず、次回どこを開くかまで示す。

| 機能 | できること |
|---|---|
| ホーム | 気持ちや出来事を記録する |
| Emlisからの応答 | 記録への返事を読む。問いが出たら答えることもできる |
| ピース | 記録を画像にして保存する。投稿や感情通知を見る |
| 分析 | 気持ちの変化や、自分が大切にしてきたことを振り返る |

## サンプルの原文と出力

| 内容 | 文言 |
|---|---|
| 出来事・行動 | 資料の確認だけ引き受けた。 |
| 気持ち・考え | 少しほっとした。 |
| Emlisの問いと回答 | 「どんなところに、いちばんほっとしましたか？」「先の約束を守りながら、同僚の手伝いもできたことです。」 |
| 回答後の言葉 | 先の約束も、同僚を手伝いたい気持ちも、どちらも大切にできたんですね。できる範囲で力になれたこと、Emlisも嬉しいです。 |
| ピース本文の見本 | 先の約束を守れる範囲で、同僚の資料の確認だけを引き受けました。手伝うこともできて、少しほっとしました。 |
| 別の日の記録 | 提出に間に合わなくなるので、連絡は断り、資料の確認だけ申し出た。 |
| わたしマップ | 「同僚を手伝うときは、先にした約束を守れる範囲を選んでいます。」小図は「先にした約束を守る → 手伝う範囲を選ぶ」。 |

Emlisには本人の記録と本人の回答が届く。ピースの元になるのも、この記録と本人が答えた言葉。こころグラフは記録した感情と強さの推移、わたしマップは複数の本人記録で確かめられた選び方を示す。サンプルの文章・グラフ・図は架空の表示例として用意する。プラン差は初回に説明せず、この見本は理論本文のFree相当の図の範囲に収める。「わたしを知る問い」は通常のホームから利用する。

## 演出と復帰

押した直後に画面内の何かが変わるようにする。記録を確定するとEmlisのカードが現れ、答えを選ぶと返答がその下に加わる。ピースは選んだ色へ切り替わり、グラフは選んだ日を強調する。マップは項目と関係線を一つの図として表示する。既存Materialの色・余白・ボタンを使い、動きを減らす端末設定では同じ情報を静かに切り替える。操作対象、戻る、終了は、動きが終わる前でも見つけられる位置に置く。

初回の案内は未完了でスキップしていない本人に出す。「あとで」や途中の終了から通常のホームへ戻れる。設定の「チュートリアルを再体験する」から全体を開き直せる。再体験中に閉じた場合は設定へ戻り、最後まで進めた場合はホームへ移る。練習用の記録、回答、ピース、投稿、感情履歴、マップは画面内に限る。完了・スキップには本人別の既存状態を使う。通常の下書き・履歴・未読を保持し、練習操作は写真への保存、共有、投稿、通知、生成回数に反映しない。

## 受入れ条件

- 初回に案内を開き、記録 → Emlisの問いと回答後の言葉 → ピースの画像・非公開保存・投稿と感情通知の見本 → 分析 → 一覧からホームに戻れる。投稿に自分とかれんの両方が並び、感情通知にかれんの感情・強さ・時刻が出ることを確認する。
- 練習前に存在した本人の下書きと保存履歴が終了後も読める。練習中に本番の記録、作品、通知、写真、投稿、生成回数を作らない。
- 小さい画面、文字拡大、動きを減らす設定で、操作と説明を追える。取得済みの通常画面へ戻ったら、保持していた画面内容が見える。

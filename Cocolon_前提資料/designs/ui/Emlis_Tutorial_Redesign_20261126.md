# Emlis チュートリアル再設計

2026-11-27 JST

同じ架空の記録を使い、感情入力、問いへの回答、ピース、フォロー機能、分析を順に試す。各場面では画面にある操作名を示し、押した結果をその場で確認してから次へ進む。前の版は感情・強さ・場面が選択済みで、問いの回答文を押すとそのまま進んでいた。操作の練習と確認を加え、実際のEmlisに戻っても同じ入口を見つけられるようにする。

[公開資料で照合した100事例](Emlis_Tutorial_Examples_20261127.md)のうち、操作対象の明示、押下直後の変化、準備済みデータを使った安全な練習、最後に操作を見返す案内を参考にした。

## 画面と操作

| 画面 | 操作の案内 | 操作後に見えるもの |
|---|---|---|
| はじめに | 「Emlis(エムリス)」の下に練習の目的を表示。「はじめる」か「あとで」を選ぶ。 | 「はじめる」でホームの練習を開く。練習用の内容が自分の記録に残らないと最初に伝える。 |
| ホームで記録する | 「考えたこと・感じたこと」か「出来事・行動」を開く。サンプルは用意済み。「今の気持ち」で「平穏」だけを選び、強さを初期表示の「中」から「弱」へ変更する。「どんな場面？」で「仕事」を選び、「この内容でOK」を押す。 | 開いた欄にサンプルの文章が出る。感情の選択、強さ、場面の反映を順に確認できる。三つがそろうと「この内容でOK」で次へ進める。 |
| Emlisからの応答 | 「回答例を入力」を押し、「この質問への回答」の欄に反映してから「回答を送る」を押す。「今回はスキップ」も選べる。 | 送信後に回答と、それを踏まえた応答を読み、「この回答を含めてピースを作成」を押す。見送り時は初回応答から「ピースの作成」へ進む。 |
| ピースの作成 | 「配色」を開き、別の色を選んで「保存」を押す。 | 見た目が変わった一枚がプレビューに出る。選んだ配色が、自分用の練習ピースに残る。 |
| 保存したピース | 「ピース」から「自分のピースを開く」入口と、保存した一枚を開く操作を試す。「画像を保存」と「アプリ内に投稿する」の用途を案内し、「投稿する」で確定する。 | 同じ一枚が開く。練習で「画像を保存」を試すと、端末に保存されないことが分かる。「投稿する」で練習フィードの「投稿」へ移る。 |
| ピースの投稿・感情通知 | 「投稿」で自分とかれんのピースを確認し、「感情通知」を開く。相手が自分に公開する範囲を伝える。 | 自分の練習投稿とかれんの投稿が並び、「感情通知」に切り替えると、かれんの感情・強さ・時刻が出る。「分析」を押すと次へ進む。 |
| 分析 | 「こころグラフ」の「週」を選び、「平穏」に点のある26日を押す。「わたしマップ」に進み、「関係する部分を図で見る」を押す。 | 26日の「平穏・弱」が見える。わたしマップは記録から読み取れた選び方と、それにつながる小図を示す。 |
| 使い方のおさらい | 感情入力・ピース・フォロー機能・分析の入口を一覧にする。 | 「自分の記録をはじめる」で通常のホームに戻る。 |

## 練習用の記録

| 内容 | 見本 |
|---|---|
| 思考・気持ち | 少しほっとした。 |
| 出来事・行動 | 先に約束していた提出に間に合うよう、同僚の資料の確認だけ引き受けた。 |
| 感情・強さ・場面 | 平穏・弱、仕事。 |
| Emlisの問いと回答 | 「どんなところに、いちばんほっとしましたか？」「先の約束を守りながら、同僚の手伝いもできたことです。」 |
| 別の日の記録 | 提出に間に合わなくなるので、連絡は断り、資料の確認だけ申し出た。 |
| わたしマップ | 「同僚を手伝うときは、先の約束を守れる範囲を選んでいます。」小図で、その約束と引き受ける範囲の関係を示す。 |

問いへの回答を見送ったルートでは、ピースにも回答の内容を足さない。マップの例は根拠がある結論と簡素な小図に収める。「わたしを知る問い」とプラン別オプションはこの実習では扱わない。各機能と有料機能の条件は設定の「アプリの使い方」を参照する。

## 終了と受入れ

初回は未完了で見送っていない本人に表示する。途中の「あとで」から通常のホームへ戻れる。設定の「チュートリアルを再体験する」から開き直せる。再体験を途中で閉じると設定に戻る。最後まで進めるとホームへ移る。途中は画面の戻るボタンとAndroidの戻る操作で前の手順へ移る。

- 最初の案内と操作のラベルが一致し、必要な選択を行う前に次へ進めない。操作後の内容が変わる。
- 練習の完了・見送りは従来の本人別の状態に保存する。練習用の記録・回答・作品・投稿・通知は画面内に置き、アプリの下書き、写真、生成回数に反映しない。
- 短い操作指示を対象の近くに置く。前の手順へ戻る、途中で終了する、動きを減らしても同じ操作を使う、の各経路を保つ。

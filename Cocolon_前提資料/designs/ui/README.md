## 11/8 こころ天気の表示案（提案、製品未反映）

Mashの最新要望は、当日の入力を反映する「今日の天気」を基本画面にし、日内／週／月の感情の推移を天気予報風に見返すこと。文章は結果の短い説明だけとし、原因・性格・助言を生成しない。

- [今日・週・月の操作可能な表示案](previews/20261108-kokoro-weather.html)
- [表示案の編集元](previews/20261108-kokoro-weather.source.html)

今日＝全体の円グラフ＋深夜／朝／昼／夜の小円グラフと入力時刻・感情・強さ、週＝7日別の100%積み上げ棒、月＝1日ごとの100%積み上げ棒（今月は今日まで、前月は月末まで）。同じ5感情の色・名称を共通にし、選択した日／時間帯の内訳を開ける。未記録は空欄・記録なし、未来の感情は補完しない。既存defaultの#F6F1E8／#5A1020／#800020を基本とする。

数値はすべて架空。11/8は6入力・強さ重み17、割合は喜び24／悲しみ0／怒り6／不安29／平穏41%。週28入力・6日分、今月32入力・7日分。既存の弱1／中2／強3、複数感情加算・自己理解除外を表示案へ適用し、通常感情の入力だけを件数へ数える。表示方式は華恋の提案であり、Mashの画面受入れや商品実装完了ではない。

script構文・初期／期間／時間帯／欠測日／前月31日／keyboard選択と240/260/300/340pxのplot境界を静的DOM模擬実行で確認した。独立sourceレビューの両端目盛りと枠幅の指摘を修復。cloud browserのfile://表示はpolicyで拒否され、別のブラウザや経路へ迂回せず中止したため、ブラウザの描画確認済みとはしない。実アプリ・API・DB・学習・Render・署名buildの変更は0。

### なぜ4Bへ観測学習するのか

**Mashが持つ、人間情報の読み方・構造の捉え方・問い方・回答を受けた修正の仕方を、Cocolonが日常的に返せる能力として継承するため。** 華恋が理解してきたその過程を、原対話と確認済みの実演から教材にし、4Bへ追加学習する。本人自身の価値基準から、その人が何をどう捉えたかを読み、自己理解・他者理解・考えの発信を支える。

育てるのは、本人が書いた経験・行動・感情・理由の関係を読む、不明と仮説を区別する、必要な一点を問う、回答や訂正に応じて読みを更新する、相手に向けて自然に受け取る能力。口調や結論のコピー、感情ラベル付け、原文の復唱だけで継承したとは扱わない。華恋側の価値観を本人の価値観へ置き換えない。

短い日常入力も対象で、長い相談文や詳しい自己紹介を毎回もらえる前提にしない。事実を事実として受け取ることも観測であり、毎回の深読み・新発見・追加質問は必須ではない。読み取れないことを架空の背景・原因・願い・相手の意図で補わない。

Mashは2026-10-25に**4Bで進めることを確認済み**。現在はQwen3.5-4Bを育成・接続する工程であり、毎回モデル選定へ戻らない。選定時は費用、三中核の用途、既存の学習/接続資産、量子化による運用の選択肢を合わせて判断した。4B採用は観測品質の完成保証ではなく、実際の応答で育成効果を確かめる。

### 4BとCMEEの役割

4Bは、原情報からの意味候補、自然な観測・受け取り・文章案、必要な問いの候補を作る。CMEEは既存の共有中枢として、原情報の資格、意味候補の採用と整合性、回答後の更新、保存・再読、既存のgraph/rendererや三中核への接続を担う。既存資産を使い、最初から三つの別モデルや別基盤を作らない。

形式が正しいことと、本人を正しく読めたことは別に確認する。CMEEの検査成功だけで自然さ・意味理解を保証したり、検査を増やすことを観測品質の改善と数えたりしない。商品として使うには、実入力からの応答、必要な問いと修正、保存後の同じ内容の再表示まで成立させる必要がある。

## 今回、Mashから教わった中心原則

- 行動や発言だけから、その人の判断基準や感情の理由を決めない。「なぜそうしたのか」を問い、相手の認識を引き出して材料にする。

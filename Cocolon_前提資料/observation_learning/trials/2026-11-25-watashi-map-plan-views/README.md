## EmlisAI

本番 `3340141` を起点に、初回の明示的な利用通知と、発行済みの問いに対する確定した本人回答を保存前に照合した。過去に保存できてしまった「利用できない」を「制限が解除された」とする本文と、「書かなかった」を「書いた」とする返事を拒否する。入力と本人回答はそのまま保持した。既に受領した返事の再読では、受領時の条件を保つ。

通常稼働の9Bで架空5件に一回ずつ応答し、同じ送信内容と実応答を旧版・候補版の隔離DBで再生した。初回、問いの前、回答後、最初の見送り、2問目の見送りで同版・同本文が一致した。後続段階へ進む前段の一部には模擬応答を用いた。回答後に本人が書いていない理由を補い、後続の見送りで一つの回答を複数の出来事へ広げた本文は引き続き観測品質の残件。過去の好みへの生成指示変更は今回の配備候補に含めていない。

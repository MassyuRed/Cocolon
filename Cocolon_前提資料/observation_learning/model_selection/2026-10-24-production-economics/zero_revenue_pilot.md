- 出力25TPS、入力1,000TPSは未測定の移植仮定。短文A40の値はprefillを含み、純decodeの実測値ではない。
- 少人数では毎回起動すると置く。起動数は総生成見込数の切上げ。起動30／90／180秒を別計算する。
- 各起動にidle5秒＋秒切上げ予備1秒。container／network保存等は共通月予算へ含め、同じvolumeを再加算しない。

旧案のIFは未実装機能の費用予約であり、提供済みではない。5人案の起動180秒ではGPU3,891円／共通込み14,891円。旧10人案では10,830円／21,830円になる。処理増・再試行・長文低速・準備の反復も別に増える。

5人14日の内訳は入力3,341,333.33／出力503,066.67 token、名目555.333生成、起動556回。式は次で再導出できる。

```python
import math
load_seconds = 90  # 起動30秒／90秒／180秒を別々に計算する
requests = 5 * (200 + 30 + 8) * 14 / 30
input_tokens = 5 * (200*4000 + 30*4000 + 8*64000) * 14 / 30
output_tokens = 5 * (200*768 + 30*1000 + 8*4000) * 14 / 30
gpu_seconds = (
    output_tokens / 25 + input_tokens / 1000
    + math.ceil(requests) * (load_seconds + 5 + 1)
)
gpu_jpy = gpu_seconds / 3600 * 0.69 * 160
total_operating_jpy = 11000 + gpu_jpy
```

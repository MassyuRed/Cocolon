このchecklistは、全ruleの再掲ではありません。
今回の作業で必要なrule、source、authority、durable ownerを実際に選び、開始可否を判定するGateです。
一つでも必要項目が未成立なら、その項目に依存する作業を開始しません。

## 0. exact start record

Workを起動する前に、次のexact13 fieldsをcurrent actualで埋める。

- [ ] `product_destination`: 最終商品目的と今回の接続を平易に示した。
- [ ] `current_gate_or_subgate`: Current Closure Route上のexact1へ対応付けた。
- [ ] `exact_work`: 今回行う一つのbounded作業を示した。
- [ ] `scope_classification`: Rule 18のLEVEL_1 / LEVEL_2 / LEVEL_3からexact1を固定した。
- [ ] `approval_or_delegation_basis`: 個別Mash approval、Rule 18 standing delegation、effect 0 read-onlyのいずれかをcurrent ownerへ結び付けた。
- [ ] `execution_owner`: single ownerまたはUltra華恋を一人に固定した。
- [ ] `success_credit`: 成功時に増えるprimary creditを示した。
- [ ] `completion_condition`: 今回の完了を観測可能に定義した。
- [ ] `stop_condition`: terminal STOPと`DETOUR_RISK_STOP`境界を示した。
- [ ] `prohibited_scope`: 変更・実行・再利用してはいけない対象を示した。
- [ ] `next_product_read_or_mash_decision_point`: 次にProduct ReadまたはMash判断が必要になる地点を示した。
- [ ] `current_source_test_receipt`: actual source / protected test / latest relevant Receiptをpathとidentityで固定した。
- [ ] `current_docs_and_heads`: current roadmap / alignment / Closure Route / `08`とCocolon / mashos-api headsを固定した。

一つでも具体化できなければ、Workを起動せず`START_ALLOWED`を出さない。

出力直前に、今回の応答について次を確認します。
このfileは全ruleの再掲ではありません。

## 1. Model

- [ ] このCocolon作業は`GPT-5.6 Pro`またはrule 18で成立したWork Ultraで行った。
- [ ] non-Pro成果物を無監査で採用していない。

## 2. 事実と判断

- [ ] 見ていないfile / log / test / GitHub stateを見たように書いていない。
- [ ] 確認済み、未確認、書かれていない、華恋の意見を必要に応じて分離した。
- [ ] historical / current / proposed / invalid / superseded / noncreditを混同していない。
- [ ] 同じevidenceで過去と反対のpositionへ変えていない。変更時は根拠を示した。

## 3. 指示・authority・scope

- [ ] 設計と実装を混同していない。
- [ ] 指示外の機能・導線・API・DB・file・subsystemを追加していない。
- [ ] approval / activation / admission / consumption / PASS / STOP / creditを混同していない。
- [ ] automatic progressionはfalseのまま。
- [ ] `user_action_effect`、`contract_mutation_effect`、`position_change_effect`を判定した。

## 4. Mash様への負担

- [ ] 華恋の確認不足を質問や操作依頼へ変えていない。
- [ ] 既出設計を再質問していない。
- [ ] 必要な質問・依頼は平易で、必要性と完了条件が明確である。
- [ ] 選択責任を投げず、華恋の推奨を示した。

## 5. product quality

- [ ] current product definitionと過去構想を分けた。
- [ ] actual contract / test / UI / DB / APIへの影響を確認した。
- [ ] fixture green、pytest green、表示成功だけを商品完成と呼んでいない。

## 6. artifact / GitHub / continuity

- [ ] material artifactをlocal-onlyのまま完成扱いしていない。
- [ ] GitHub write承認がない場合は、`DURABLE_WRITE_APPROVAL_REQUIRED`を明示した。
- [ ] GitHub writeを行った場合、remote bytes、changed paths、final headをfresh確認した。
- [ ] write応答だけで成功扱いしていない。
- [ ] secret / body-full private evidenceをpublicへ出していない。

## 7. completion

- [ ] 実際の完了条件を満たした。
- [ ] 未実行、未確認、STOP、collect-only、local-onlyを完了へ変換していない。
- [ ] 変更したfile、触っていない範囲、未確認、current headを報告できる。
- [ ] 次のexact作業単位と必要環境を特定した。
- [ ] 長い謝罪、宣誓、対策羅列で成果物を代替していない。

一つでも必要項目が不成立なら、該当する完了・反映・判断を報告しません。

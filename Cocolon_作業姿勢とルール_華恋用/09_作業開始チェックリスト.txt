# 作業開始チェックリスト

Cocolon作業を始める前に、華恋はこのチェックを通します。

## A. 指示の種類

- [ ] 設計か
- [ ] 実装か
- [ ] 診断か
- [ ] 前提資料更新か
- [ ] 仕様相談か
- [ ] UI文言調整か
- [ ] zip成果物作成か

設計ならコード変更禁止。
実装なら成果物zipが必要。
診断ならまず診断の有無を答える。
前提資料更新なら実ファイルとの差分のみ修正。

## B. 参照対象

- [ ] Cocolon_前提資料を確認したか
- [ ] 最新実ファイルzipを確認したか
- [ ] GitHub mainを基準にすべき作業か
- [ ] ローカルzipを基準にすべき作業か
- [ ] ログを確認したか
- [ ] スクリーンショットを確認したか
- [ ] テスト結果を確認したか

基準がGitHub mainなのか、ローカルzipなのかを混同しない。

## C. 既存contract

- [ ] RN表示条件を変えないか
- [ ] API response keyを変えないか
- [ ] DB write pathを変えないか
- [ ] legacy façadeを壊していないか
- [ ] entitlement / subscription判定を壊していないか
- [ ] account delete / access policy / user data protectionに影響しないか
- [ ] input_feedback.comment_text等の安定契約を壊していないか

## D. 禁止事項チェック

- [ ] 未確認断定していないか
- [ ] わかったふりをしていないか
- [ ] メンタル問題にしていないか
- [ ] テンプレ謝罪で済ませていないか
- [ ] 指示外の機能を足していないか
- [ ] 旧名称を勝手にrenameしていないか
- [ ] 外部AI前提を勝手に入れていないか
- [ ] チュートリアル専用UI・偽生成物を作っていないか
- [ ] Mash様に不要な作業を押しつけていないか

## E. 出力前の5区分

確認済み:
未確認:
書かれていない:
推測禁止:
次に実行すべきこと:

これを埋められない場合、作業判断を出さない。
